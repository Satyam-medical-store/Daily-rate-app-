Aapki dukaan ke liye maine ek complete ready-to-use Web App ka code taiyar kar diya hai. Ise aap apne Mobile ya Computer ke browser (Chrome vagera) me direct chala sakte hain, aur isme internet ki bhi jarurat nahi padegi (data aapke phone/PC me hamesha save rahega). Is app me aapki saari requirements shamil hain: 1. Daily Product Entry (Product ka naam, quantity, rate). 2. Category & Sub-Category: - Medicine (Tablets, Syrups, Injections, Ointment, etc.) - Cosmetic (Skincare, Haircare, Makeup, Perfume, etc.) - Surgical (Gloves/Mask, Bandage/Cotton, Syringes, etc.) - General Item (Toiletries, Stationery, Snacks, etc.) 3. Daily Rate Edit Option: Jab chahein purana rate badal sakte hain. 4. Date Modify Option: Entry karte waqt ya baad me date badalne ki suvidha. 5. Search & Excel/CSV Export: Product search karne aur sara data Excel me download karne ka option. Step 1: Is code ko chalane ka aasan tarika: 1. Apne phone ya computer me Notepad (ya koi bhi Text Editor) kholein. 2. Niche diye gaye code ko Copy karke Notepad me Paste kar dein. 3. File ko save karte waqt uska naam dukaan.html rakhein (.html lagana jaruri hai). 4. Ab us file par click karein—ye aapke mobile/computer ke Chrome browser me ekdum app ki tarah khul jayegi.
